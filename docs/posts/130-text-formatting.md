Discord formats your messages with a few symbols (it's called *markdown*). Useful for your village rules and announcements.

## Titles
```
# Big title
## Sub title
### Small title
```
# Big title
## Sub title
### Small title
---
## Lists
```
- item
- item
1. first
2. second
```
- item
- item
1. first
2. second

## Text style
```
*italic*  **bold**  ***bold italic***  __underline__  ~~crossed~~  ||spoiler||
```
*italic*  **bold**  ***bold italic***  __underline__  ~~crossed~~  ||spoiler||
---
## Quotes and code
```
> quote
`code`
-# small text
```
