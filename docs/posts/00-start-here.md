# Welcome to the bot documentation
Sakuretsu Bot manages the villages of the server, the Blood Clash help, the mission board and a few community features.

Each feature has its own post in this forum. Pick one below, or filter the posts with the tags at the top of the forum.

## How to use a command
1. Type `/` in the message bar
2. Pick the command in the list (or keep typing its name)
3. Fill the options. Some of them show a list while you type: pick a value from it
4. Send the message

Most answers of the bot are only visible to you.
💡 The commands written in blue in this documentation can be clicked to use them directly.
